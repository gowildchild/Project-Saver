# 🚀 Project Saver - Modules

The modules provide the following system functions:

* **manager.py**: Loads core system configurations, handles application autoload paths, and builds your global menu presentation settings.
* **custom.py**: Operates as a customized presentation engine rendering real-time tracking metrics gathered by the Project Saver application daemon.
* **debug.py**: Exposes deep runtime diagnostic data tables to simplify testing infrastructure and streamline custom plugin development.
* **shutdown.py**: Delivers simple execution loops to instantly trigger machine shutdown states or easily abort pending system countdown procedures.
* **menu.py**: Manages execution navigation routing for internal backend add-ons and direct terminal action items.
* **archiver.py**: Houses the core application engine refactored into a portable layout for handling file systems extraction and background compression packaging tasks.
