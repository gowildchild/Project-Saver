# 🚀 Project Saver - Modules

The modules have the following function:

*manager.py* This is the manager module loading the autoloads and settings and menu display settings
*custom.py* Custom plugin showing all current data of Project Saver
*debug.py* Debugging info to create custom addons, to see if everything is all ok
*shutdown.py* Shutdown utility which allows easy access for shutdown and cancel shutdown
*menu.py* Custom menu to allow modules and direct menu items
*archiver.py* This will be the Project Saver in module format, extraction and archiving
